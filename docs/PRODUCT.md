# 여쭈어 (여JJU) 제품 요약

- 갱신일: 2026-10-14
- 역할: 지금의 제품 범위를 정하는 가장 짧은 기준 문서. 범위 판단은 이 문서가
  우선하고, 기능별 세부 동작은 `MVP_FUNCTIONAL_SPEC.md`의 요구사항 ID를 따른다.
- 저장소·기술 식별자는 `TravelGuide v2`, 표시 브랜드는 `여쭈어`.

## 한 문장

여행이 틀어지는 순간, 인증된 현지인 여러 명에게 지금 필요한 판단을 묻는
여행지 실시간 도움방.

## 누구의 어떤 문제인가

- **여행자**: 날씨, 휴무, 교통 지연, 혼잡, 예약 취소처럼 계획이 어긋난 순간에
  검색 결과보다 "지금 이곳을 아는 사람"의 판단이 필요하다. 낯선 사람의 말은
  믿기 어렵고, 1:1 매칭은 응답을 기다리다 끝난다.
- **현지인**: 아는 것을 짧게 알려주고 기여를 인정받는다.
- **운영자**: 인증 심사와 신고 처리로 방의 신뢰를 지킨다.

## 검증 중인 가설

1. 여행자는 돌발 상황에서 검색보다 현지인의 즉시 판단을 원한다.
2. 여러 현지인이 보는 지역방이 1:1 매칭보다 응답 가능성이 높다.
3. 인증 배지와 답변 근거 표시가 낯선 사람에 대한 불신을 줄인다.
4. 실시간 대화와 토픽-답변-해결 구조를 함께 두면 속도와 명확성을 모두 얻는다.

## 하지 않는 것

새로 하려면 오너 결정과 ADR이 먼저 필요하다.

- 1:1 매칭, 개인 채팅, 스와이프
- 결제, 코인, 정산, 리워드, 현지인 순위·평점
- AI 답변·요약·신고 필터, 번역, 다국어
- 음성·영상 통화, 읽음 표시, 타이핑·온라인 표시
- 경로 안내, 여행지 전역 지도 탐색
- 백그라운드 웹 푸시 서버
- 제주 외 지역의 인증 실시간방 (브랜드 문구는 여러 지역으로 확장 가능하게 유지)
- 마이크로서비스, 메시지 큐, 이벤트 소싱

1. 운영 중인 기능의 버그와 막히는 흐름
