# T14 브라우저 알림

## 목표

인증 방을 열어 둔 사용자가 다른 탭을 보고 있을 때 새 메시지와 새 답변을
놓치지 않도록, 현재 열린 웹앱이 제공하는 브라우저 알림을 추가한다.

## 범위

- 방 헤더에서 이 브라우저의 알림 권한과 사용 상태를 확인하고 변경한다.
- 알림 권한은 반드시 사용자의 버튼 동작으로 요청한다.
- 알림을 켠 상태에서 문서가 보이지 않을 때만 다른 사용자의 새 메시지와
  새 답변을 알린다.
- 메시지 알림은 방으로, 답변 알림은 해당 토픽 상세로 이동한다.
- 권한 거부, 미지원, 사용 중, 사용 안 함 상태를 명확한 한국어로 표시한다.
- 페이지가 열려 있을 때만 동작하며 서비스 워커, 서버 푸시, 새 backend
  endpoint는 추가하지 않는다.

## 인수 조건

- 자신의 메시지·답변으로 알림이 발생하지 않는다.
- 현재 탭이 보이는 동안 시스템 알림이 발생하지 않는다.
- 중복 Socket 이벤트는 한 번만 알린다.
- 권한을 거부한 브라우저에는 반복해서 권한 요청을 시도하지 않는다.
- 알림을 누르면 관련 화면으로 이동하고 창에 포커스한다.
- 알림 사용 선택은 같은 브라우저 새로고침 후 유지된다.
- 미지원 환경에서도 방과 실시간 기능은 정상 동작한다.
- 프론트엔드 테스트, lint, typecheck, build가 통과한다.
