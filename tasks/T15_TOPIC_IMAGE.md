# T15 토픽 사진 첨부

## 목표

참여자가 토픽을 만들 때 현재 상황을 설명하는 사진 한 장을 근거 자료로
첨부하고, 인증된 방 참여자만 목록과 상세에서 볼 수 있게 한다.

## 범위

- 직접 만드는 토픽에 JPEG, PNG, WebP 사진 한 장을 선택적으로 첨부한다.
- 최대 크기는 10 MiB이며 선언 MIME과 파일 시그니처를 함께 검증한다.
- 사진은 비공개 저장소에 저장하고 공개 정적 URL을 만들지 않는다.
- 토픽 목록에서는 작은 근거 사진으로, 상세에서는 본문 아래 증거 패널로
  표시한다.
- 토픽이 운영 정책으로 숨겨지면 사진 메타데이터를 응답에서 제거하고 파일
  조회도 거부한다.
- DB 저장 실패 시 먼저 업로드한 파일을 정리한다.
- 메시지를 토픽으로 전환하는 기존 흐름은 사진 없이 그대로 유지한다.

## 인수 조건

- 사진 없이 만드는 기존 JSON 토픽 API가 계속 동작한다.
- 유효한 사진이 있는 multipart 토픽 생성이 DB·Socket·REST에 동일한 공개
  계약으로 반영된다.
- 미인증 사용자와 다른 여행지 권한 사용자는 사진을 조회할 수 없다.
- 크기 초과와 MIME 위조는 토픽 생성 전에 거부된다.
- 숨김 토픽의 사진 endpoint는 404를 반환한다.
- 업로드 후 DB 실패 시 고아 파일이 남지 않는다.
- 프론트와 백엔드 format, typecheck, tests, lint, build가 통과한다.
