# T17 공개 기여자 프로필

## 목표

답변 작성자의 공개 프로필에서 인증 지역과 실제 정보 기여 이력을 확인할 수 있게
하여, 평점이나 순위 없이 답변의 신뢰 근거를 보강한다.

## 범위

- 기존 공개 프로필 API에 소개, 가입일, 공개 활동 통계를 추가한다.
- 숨김되지 않은 답변 수와 숨김되지 않은 토픽에 채택된 답변 수만 집계한다.
- 답변 카드의 작성자 이름에서 공개 프로필로 이동할 수 있게 한다.
- 로딩·오류·빈 통계를 포함한 반응형 공개 프로필 화면을 만든다.
- 이메일, 증빙 파일, GPS와 관리자 정보는 공개하지 않는다.

## 인수 조건

- 로그인 사용자가 `/app/users/:userId`에서 공개 프로필을 확인한다.
- 통계는 `answerCount`, `acceptedAnswerCount` 두 정수로 반환된다.
- 숨김 답변과 숨김 토픽의 채택은 통계에서 제외된다.
- 유효한 현지인 인증만 인증 지역과 인증 시점을 노출한다.
- 존재하지 않는 사용자는 기존 `USER_NOT_FOUND` 문제 응답을 유지한다.
- backend/frontend 테스트와 품질 명령이 통과한다.
