# T16 토픽 자동 만료

## 목표

마감 시간이 지난 진행 중 토픽을 DB에서도 `EXPIRED`로 전환하여 진행 중
목록과 실시간 화면이 같은 상태를 보게 한다.

## 범위

- `QuestionStatus`에 `EXPIRED`를 추가하는 Prisma migration을 만든다.
- API 시작 시 한 번, 이후 60초마다 만료 대상 토픽을 작은 batch로 처리한다.
- `status=OPEN`이고 `expiresAt <= now`인 레코드만 조건부 갱신한다.
- 커밋 후 기존 `room.question.updated` 이벤트로 만료 상태를 알린다.
- 프론트는 만료 토픽을 진행 중·해결됨 목록 모두에서 제거하고, 상세 화면의
  상태와 접근성 알림을 갱신한다.
- 테스트 환경에서는 자동 timer를 시작하지 않고 만료 로직을 직접 검증한다.

## 인수 조건

- 정확히 마감 시각에 도달한 OPEN 토픽이 EXPIRED가 된다.
- RESOLVED·REMOVED·이미 EXPIRED인 토픽은 변경하지 않는다.
- 동시에 두 실행이 같은 토픽을 잡아도 하나의 전환과 이벤트만 발생한다.
- 만료 이벤트는 DB 커밋 이후에만 발행된다.
- 만료 토픽은 새 답변·채택·해결이 계속 거부된다.
- 앱 재시작 시 중단 동안 쌓인 만료 대상도 처리된다.
- backend/frontend 관련 테스트와 품질 명령이 통과한다.
