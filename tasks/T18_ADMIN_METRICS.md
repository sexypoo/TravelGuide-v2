# T18 관리자 KPI 대시보드

## 목표

운영자가 실제 PostgreSQL 데이터를 기준으로 질문→답변→해결 흐름과 현지인
기여 현황을 한 화면에서 확인한다.

## 범위

- 관리자 전용 `GET /admin/metrics`를 구현한다.
- 숨김되지 않은 질문·답변만 KPI에 반영한다.
- 질문 수, 답변 질문 비율, 평균 최초 답변 시간, 10분 내 답변 비율,
  해결률, 채택률, 현지인별 답변 수를 반환한다.
- 관리자 화면에 반응형 지표판과 빈 상태를 제공한다.

## 인수 조건

- 비관리자는 API와 화면에 접근할 수 없다.
- 분모가 0인 비율은 0이며 최초 답변 시간이 없으면 null이다.
- 시간 지표는 DB의 질문·답변 생성 시각으로 계산한다.
- 현지인별 집계는 답변 당시 LOCAL 또는 BOTH인 공개 답변만 포함한다.
- backend/frontend 관련 품질 명령이 통과한다.
